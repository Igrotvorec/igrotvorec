# Игротворец

Генератор HTML5 мини-игр по текстовому запросу. Пишете «замути змейку для бабушки» — примерно через две минуты получаете играбельную игру по ссылке: нарисованный ИИ мир, уровни, бонусы, музыка, крупные кнопки для пожилых. Игры self-contained и открываются в WebView без серверных зависимостей.

## Как это работает

```
запрос ─▶ spec (LLM, structured output) ─▶ профиль аудитории + наблюдения
        ─▶ рецепт жанра (19 жанров) + числа баланса ─▶ код сцены Phaser 3 (LLM) ∥ фон и лист спрайтов (ИИ)
        ─▶ статическая проверка (acorn, запрещённые API, обязательные хуки) ─▶ ≤1 исправление
        ─▶ сборка одного HTML: runtime + конфиг + код ─▶ /g/:versionId (CSP sandbox)
        ─▶ превью: runtime делает smoke-прогон и шлёт диагностику ─▶ при ошибке ≤1 автоисправление
        ─▶ /play/:gameId — полноэкранная ссылка, QR, версии
```

- **Runtime (`packages/runtime/src/phaser-kit.js`)** — встраивается в каждую игру вместе с Phaser 3.90: экраны старта/победы/поражения, пауза при сворачивании, текстуры из встроенных картинок, восьмибитная музыка и звуки, готовые эффекты `GG.fx`, честные хитбоксы `GG.hitbox`, жизни/разминка/прощение `GG.damage`, рекорд, самопроверка. Правила, сущности, физику, уровни и условия исхода пишет LLM — шаблона игры нет. Старые игры на прежнем мини-движке (`kit.js`) продолжают работать.
- **Рецепты жанров** — `research/genre-recipes*.json`: прогрессия с числами, типы объектов, бонусы, эффекты и типичные ошибки генерации для 19 жанров, источники рядом.
- **Адаптация под аудиторию** — профили в `packages/shared/src/profiles.ts`: размер целей и шрифтов, скорость, длина раунда, палитра, чего избегать. Источники указаны у каждого профиля.
- **Статистика** — оболочка `/play` собирает события (старт раунда, победа/поражение, длительность, повтор). Сегменты аудитория × жанр с достаточным числом сессий подмешиваются в генерацию новых игр (`apps/server/src/stats.ts`).
- **Демо и презентация** — сценарий, цифры и ответы на вопросы в [docs/demo.md](docs/demo.md).
- **Безопасность** — подробно в [docs/security.md](docs/security.md): тест побега из песочницы и red team prompt-инъекций.
- **Изоляция** — игра работает в `sandbox="allow-scripts"` без same-origin, документ отдаётся с CSP `sandbox` и `connect-src 'none'`; хранилище и телеметрия идут через доверенную оболочку по postMessage.

## Запуск

```bash
bun install
cp .env.example .env   # LLM_BASE_URL, LLM_API_KEY — любой OpenAI-совместимый эндпоинт
bun run dev            # сервер :8787 + Vite :5173
```

Продакшен: `docker compose up -d --build` (приложение + Caddy, домен `DOMAIN` в `.env`). Пошагово: [docs/deploy.md](docs/deploy.md).

## Структура

```
apps/server     Hono на Bun, bun:sqlite, OpenAI SDK, пайплайн генерации
apps/web        React + Vite: генератор, превью, правки, версии, галерея, статистика
packages/runtime  kit.js/kit.css + сборщик HTML
packages/shared   схема spec, протокол postMessage, профили аудиторий, типы API
tools/          dev-скрипты: try-game (плейтест в Chrome), bench (пакетная генерация)
```
